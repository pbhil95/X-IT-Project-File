# OASIS Staff Details Form

A single-page form (`index.html`) with the same fields as the CBSE OASIS
"Staff Details" page, for collecting teachers' details before portal entry.

- Works as it is: a teacher fills it, presses **Submit**, checks the summary and
  presses **Print / Save as PDF**.
- Optional: to collect all submissions in a Google Sheet, follow the steps at the
  top of `sheet-receiver.gs` and paste the web-app URL into `SHEET_URL` in `index.html`.

The page itself stores no data.
